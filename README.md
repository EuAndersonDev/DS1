# Repositório de Desenvolvimento de Sistemas (DS) - Java POO e Swing

Este repositório contém os projetos, exercícios e anotações da disciplina de Desenvolvimento de Sistemas (DS), com foco em Programação Orientada a Objetos (POO) e desenvolvimento de interfaces gráficas usando Swing em Java.

## Conteúdos Abordados

1. **Programação Orientada a Objetos (POO)**
   - **Classes e Objetos**: Conceitos fundamentais de modelagem e criação de classes e instâncias.
   - **Encapsulamento**: Utilização de modificadores de acesso e métodos getters/setters.
   - **Herança**: Implementação de hierarquias de classes e reutilização de código.
   - **Polimorfismo**: Uso de sobrecarga e sobrescrita de métodos para flexibilidade de código.
   - **Interfaces e Abstração**: Criação de interfaces e classes abstratas para estruturas mais robustas.

2. **Java Swing - Interface Gráfica**
   - **Componentes Básicos**: Janelas (JFrame), botões (JButton), rótulos (JLabel), caixas de texto (JTextField) e outros.
   - **Layouts**: Organização de componentes usando gerenciadores de layout (BorderLayout, FlowLayout, GridLayout, etc.).
   - **Eventos**: Manipulação de eventos de interface, como cliques e ações de usuário.
   - **Formulários**: Criação de formulários interativos com validação de dados e captura de informações.
   - **Projetos Práticos**: Desenvolvimento de miniaplicações com interface gráfica para fixação dos conceitos de POO e Swing.

## Como Utilizar este Repositório

Este repositório é organizado para que os tópicos de POO e Swing possam ser estudados separadamente ou em conjunto. Cada projeto contém um README com instruções específicas e pré-requisitos, quando necessário.

## Tecnologias

- **Java SE**
- **Swing** para interfaces gráficas
- **IDE recomendada**: IntelliJ IDEA, Eclipse ou NetBeans
